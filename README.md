# Phillip Miranda — Currículo online

Currículo interativo em HTML, CSS e JavaScript puro (sem frameworks).

- Foto em preto e branco que fica colorida ao passar o mouse (no celular, ao tocar)
- Links para LinkedIn, GitHub, e-mail e WhatsApp
- Experiência em linha do tempo expansível, filtro de cursos e animações de entrada
- **Exportar PDF**: o script monta duas folhas A4 fixas (com a faixa lateral em cada uma) e reduz o conteúdo automaticamente se precisar caber — escolha "Salvar como PDF"

Para atualizar, edite `index.html` (conteúdo), `styles.css` (visual e regras de impressão) e `script.js` (interações).
